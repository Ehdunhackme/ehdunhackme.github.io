# State boundaries

`states-albers-10m.json` is pinned to us-atlas 3.0.1:
https://cdn.jsdelivr.net/npm/us-atlas@3.0.1/states-albers-10m.json

Source: https://github.com/topojson/us-atlas

The geometry comes from the US Census Bureau's 2017 cartographic state
boundaries, projected with Albers USA to a 975 by 610 viewport. It is used
only to draw state outlines, not to supply election results or district data.
The package license is included in `LICENSE`.
